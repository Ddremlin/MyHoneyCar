# MyHoneyCar

Ухаживай за своим автомобилем. Не забывай оплачивать страховку. Статистика расходов и многое другое...

Android-приложение для учёта расходов на свою машину со встроенной диагностикой ELM327 (OBD-II) и разбором данных нейросетью Claude.

## Возможности

- **Расходы** — журнал по месяцам, категории, заправки (литры, цена, полный бак), фото чеков.
- **ТО** — регламент по пробегу и месяцам; отметка «выполнено» создаёт расход.
- **Итоги** — за месяц, год и всё время, по категориям, стоимость километра, расход л/100 км (от полного бака до полного).
- **OBD** — подключение к адаптеру ELM327 по Bluetooth, датчики, коды ошибок (DTC), VIN, пробег, поездки в фоне.
- **Авто** — несколько машин (марка, модель, поколение из встроенного каталога), валюта, резервная копия в JSON/ZIP с фото, экспорт в CSV.
- **Анализ нейросетью** — коды ошибок и показания датчиков разбирает Claude с учётом модели, пробега и ТО. Нужен свой ключ Anthropic API: он хранится только на телефоне и не попадает в резервную копию.

Все данные хранятся локально в `filesDir/data.json`, сервера у приложения нет.

## Сборка

Нужен JDK 21 и Android SDK (путь указывается в `local.properties`).

```bash
./gradlew testDebugUnitTest assembleDebug
```

Для release-сборки создайте `keystore.properties` в корне проекта (он в `.gitignore`):

```properties
storeFile=/путь/к/release.jks
storePassword=...
keyAlias=...
keyPassword=...
```

Потом соберите и установите:

```bash
./gradlew assembleRelease
adb install -r app/build/outputs/apk/release/app-release.apk
```

## Симулятор ELM327

`tools/elmsim.py` — эмулятор адаптера по TCP, чтобы проверять вкладку OBD без машины.

## Технологии

Kotlin, Jetpack Compose, Material 3, org.json, Anthropic Java SDK.
